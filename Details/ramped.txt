## What the project is

**Ramped Careers** is an AI job-search and job-application platform. The backend is Django and Django REST Framework, running on Google App Engine. It:

- **Brings in job listings every day** from an external job data provider (Source Stack) using scheduled cron jobs.
- **Enriches each job with OpenAI.** It runs batch jobs for embeddings, cleaning up titles and locations, parsing job descriptions and extracting structured info. Google Cloud Tasks queues handle this work.
- **Matches jobs to users** with a semantic search that uses vectors stored in PostgreSQL (pgvector).
- **Parses uploaded resumes** with PyMuPDF and GPT, then **creates resumes and cover letters tailored to each job**, rendered as PDFs with WeasyPrint.
- **Tracks applications** on a job tracker, and works with a **Chrome extension that applies to jobs automatically**.
- Handles **sign-in with Firebase and JWT tokens**, sends **Slack notifications**, and receives a **Coda webhook**.

**Stack:** Python, Django, DRF, PostgreSQL and pgvector, Firebase/Firestore, OpenAI (Batch API and embeddings), Google App Engine, Cloud Tasks, Cron, Cloud Logging, AWS S3 (boto3 and django-storages), WeasyPrint, PyMuPDF.
